# Parteas City — map Bonelab (PC)

Map RP Bonelab « Parteas City ». Les versions compilées sont dans les **Releases** (fichier `Parteas.ParteasCity_PC.zip`).

## Installation manuelle
1. Télécharger `Parteas.ParteasCity_PC.zip` dans la dernière Release.
2. Dézipper dans `%USERPROFILE%\AppData\LocalLow\Stress Level Zero\BONELAB\Mods\`
   → on doit obtenir `Mods\Parteas.ParteasCity\Parteas.ParteasCity.pallet.json`.
3. Lancer Bonelab. Supprimer l'ancien dossier `Parteas.ParteasCity` avant chaque mise à jour.

## Identifiants (barcodes) pour les scripts MelonLoader
- Pallet : `Parteas.ParteasCity`
- Niveau : `Parteas.ParteasCity.Level.ParteasCity`

## Mise à jour automatique (launcher)
Dernière version : `GET https://api.github.com/repos/Parteas/ParteasCityXFlashCos/releases/latest`
→ comparer `tag_name` à la version installée, puis télécharger l'asset `Parteas.ParteasCity_PC.zip`.
